# D11 MapPointと観測関係

図の対応：DFD（Data Flow Diagram、データの流れを示す図）の「初期地図・観測関係」「地図点・参照画像」「新しいMapPoint・修正した姿勢・観測関係」。接続は **A06/P02 → D10 → A09/A10**。A06/P02で三角測量した位置から作る純単眼のMapPointを中心に扱う。

## 三次元位置を画像の観測へ結び付ける

MapPoint（地図点、以下MP）は、地図上の三次元位置だけを保存する点ではない。その点をどのKeyFrame（キーフレーム、以下KF）が、画像内のどの特徴として観測したかも保持する。これにより、同じ点を別の画像へ投影して対応を探し、位置や姿勢を見直せる。

生成時の主な入力は三次元位置、参照KF、所属Mapである。生成後にKFとの観測関係や代表情報を追加・更新し、追跡・局所地図処理へ位置と照合情報を渡す。コンストラクタを呼ぶだけで、全観測や代表記述子が完成するわけではない。

| 保持情報 | 役割と注意 |
| --- | --- |
| `mWorldPos` | 所属Mapの世界座標での位置、`Eigen::Vector3f`。更新可能で、単眼では任意尺度の長さ |
| `mpMap` | 所属Mapへの参照。位置がどの地図座標系に属するかを区別する |
| `mpRefKF` | 代表情報の計算などで基準にする一つのKF。観測KF全体と同じものではない |
| `mObservations` | 観測KFから、その画像の特徴添字へ引く表。実体は`map<KeyFrame*,tuple<int,int>>` |
| `nObs` | `Observations()`が返すintの観測カウンタ。表のキー数とは別の値 |
| `mDescriptor` | 観測された二進記述子から選ぶ代表記述子。画素やbitの単純平均ではない |
| `mNormalVector` | 観測カメラから点へ向かう方向を平均した三成分の情報。物体表面の法線ではない |
| `mfMinDistance/mfMaxDistance` | 参照KFからの距離と特徴の尺度段から得る探索・尺度予測用範囲 |

代表記述子は、観測記述子どうしの距離を比較して一つを選び、cloneして保持する。現行の選択指標は自己距離0を含む整列列の中央下側要素で、偶数個の中央二値を平均する通常の中央値とは限らない。選択式の全展開はせず、複数の見え方から照合用の代表を選ぶ役割を押さえる。

方向の更新では各観測方向を単位ベクトルにして平均するが、最後の平均結果を再び単位長へ正規化していない。従って`GetNormal()`の値が必ず単位ノルムであるとは扱わない。距離範囲も、深度センサの測定値や誤差区間ではなく、見え方の尺度との整合を調べる情報である（A10）。

## KF側と点側の二つの関連

純単眼の観測は、点側では`KF → (j,-1)`として保持される。jはそのKFの特徴配列にある非負の整数添字で、二番目の`-1`は右側観測がないことを示す番兵値である。KF側は、その特徴jの`mvpMapPoints[j]`から同じ点を参照する。

例えば同じ点Pを、KF0の特徴2とKF1の特徴7が観測したと仮定する。

| 保存する側 | 観測関係の仮定例 |
| --- | --- |
| 点P | `{KF0:(2,-1), KF1:(7,-1)}` |
| KF0 | `mvpMapPoints[2] = P` |
| KF1 | `mvpMapPoints[7] = P` |

このPはMP実体への参照であり、三次元座標ベクトルそのものではない。観測ごとに別の三次元点を複製するのでもない。A06の生成経路は、KF側の`AddMapPoint`と点側の`AddObservation`をそれぞれ呼ぶ。片側の代入だけで、常に両側が自動的にそろうと考えない。

現行の純単眼では右画像座標が`-1`であり、通常の`AddObservation`一回で`nObs`は1増える。上の二観測を一回ずつ追加しただけなら2である。ただし既存KFの表項目を更新した後にも加算するので、この関数自体は重複追加を防いでいない。従って単眼でも、`Observations()`を無条件に「異なる観測KFの数」と読み替えない。他センサの一回で2を加える枝も単眼へ流用しない。

## 観測関係が再投影を結ぶ

同じMap内の点を、観測KFの姿勢と校正から画像へ戻してみる。以下は歪み補正後の画素を使うPinHoleモデルの整理式であり、最適化算法全体の式ではない。

\[
P_i=R_{iw}P_w+t_{iw}=(X_i,Y_i,Z_i)^{\mathsf T},
\qquad
\widehat u_{ij}=\begin{pmatrix}f_xX_i/Z_i+c_x\\f_yY_i/Z_i+c_y\end{pmatrix},
\qquad e_{ij}=\bar u_{ij}-\widehat u_{ij}.
\]

| 記号 | 型・座標・単位・前提 |
| --- | --- |
| \(P_w\) | 点Pの世界座標を表す長さ3の実数列ベクトル。MPへの参照Pとは異なる |
| \(i,j\) | iは観測KFを区別する添字、jはそのKF内の特徴添字。いずれも整数の番号 |
| \(R_{iw},t_{iw}\) | 世界w→KF iのカメラへの3×3回転と三成分並進。回転は正規直交・行列式＋1で無次元 |
| \(P_i,X_i,Y_i,Z_i\) | カメラ座標の三成分ベクトルとその各成分。投影では正深度Z_i＞0を仮定 |
| \(f_x,f_y,c_x,c_y\) | このKFに使う焦点距離二成分と主点二成分、単位pixel。焦点距離は正とする |
| \(\bar u_{ij}\) | 補正後特徴`mvKeysUn[j].pt`の二成分観測画素、単位pixel。横棒は補正済みの目印 |
| \(\widehat u_{ij},e_{ij}\) | 二成分の予測画素と観測−予測の残差、単位pixel。帽子は予測の目印 |
| 上付き\(\mathsf T\) | 転置。ここでは列ベクトルとして成分を並べる記法 |

位置と並進は同じ地図の長さ単位であり、純単眼でメートルが保証されるわけではない。カメラ座標は右・下・前方が正のX・Y・Z方向、画像は右・下が正の画素方向である。歪み補正前の特徴座標を、この式へ同じものとして代入しない（D03）。

数値例として、P_wが`(1,0,5)`、回転なし・並進ゼロ、焦点距離が両軸500 pixel、主点が`(320,240)` pixelと仮定する。予測は`(420,240)` pixelになり、観測が`(421,239)`なら残差は`(1,-1)` pixelとなる。この校正値・点位置は説明用で、現行設定や実測結果ではない。

観測表は、どのKFの姿勢とどの特徴画素をこの比較に使うかを結び付ける。残差は画像上のずれであり、そのまま三次元位置誤差や地図全体の正しさを示す値ではない。姿勢だけを調整するA09と、姿勢・点を調整するP02の違いは既章を参照する。

## 生成後の更新、無効化、置換

初期化やLocalMappingは、三角測量した位置から点を生成し、両側の観測関係を登録して代表記述子・方向・距離情報を更新する。位置も`SetWorldPos`で変更できる。観測の追加・削除、最適化、融合に伴って更新される構造であり、一度得た座標を永久に固定するものではない。

`SetBadFlag`はbadを設定し、点の観測表を空にし、各KFの対応を解除してMapの集合から除く。この関数内で点実体を即座にdeleteするわけではない。論理的に利用対象から外すことと、メモリ解放を区別する。

`Replace`は旧点をbadにし、置換先を記録する。置換先が未観測のKFなら対応を移し、既に観測済みなら旧点側の重複対応を外す。その後、計数情報や代表記述子を更新して旧点をMap集合から除く。二点の座標を単純平均する操作ではない。点の再利用・置換という構造上の意味に絞り、融合算法はP02/P03へ委ねる。

## 理解確認

1. KF側の特徴添字と、MP側の観測表は何を結ぶか。
2. `Observations()`、異なる観測KF数、平均方向のノルムを、それぞれ無条件に同一・単位値と扱えるか。
3. 再投影残差の単位は何か。点の無効化・置換は即deleteや座標平均を意味するか。

答えの要点：同じ三次元点と各画像の観測／計数条件と平均の実装を区別する／pixel、どちらの処理もその意味にはならない。
