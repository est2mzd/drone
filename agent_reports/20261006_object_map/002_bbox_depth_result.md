# 段1の結果: 箱の中の深度は、クラスではなく面の一様さを見ている

小監督者。作業者Aが映像を取り、作業者Bが `object_map/extract_objects.py` を実行した。大監督者の完了条件は満たしている。トラックと世界座標には入っていない。

## データ

28フレーム。Mini 3 の `mini3_bridge/pc/recordings/20261002_001816.mp4` から2枚、ネットの室内映像13本から各2枚。出典は `object_map/video_sources.txt`。先頭が屋外や図面だったものは、部屋が写る秒へずらすか捨てた。残したのは YouTube 6本（部屋が写る12秒）と Pexels 7本（先頭8秒）。

深度は `DA3-SMALL`、長辺 504、1枚ずつ。1枚の forward は CPU で約 1.1 秒。この呼び方のままではリアルタイムの自己位置には間に合わない。ここでの成果は速度ではなく、観測の定義である。深度の単位は相対で、メートルの位置は書いていない。

## 数

検出 100。内側が 400 画素未満で捨てたのが 1。残り 99 について、相対差の中に 50% 以上の画素が入るか。

| 相対差 | 50% 以上になった箱 |
| --- | --- |
| 15%（採用の規定） | 96 / 99 |
| 10% | 84 / 99 |
| 5% | 52 / 99 |

15% で落ちたのは 3 つだけ。

- 人。扉の向こうの人で、箱に奥の廊下まで入っている。割合 0.44。`008_IXc2JJGk3oE` の 3.0 秒。
- ダイニングテーブル 2 つ。天板と脚、床が一つの箱に入っている。割合 0.44 と 0.40。

5% で 50% 以上だった 52 箱のうち、一致画素が一つの連結成分だったのは 45。残る 7 は同じ深さでも画素が分かれている。

クラスごとの 15% での中央割合は `object_map/out/summary.yaml`。椅子 19、人 13、ソファ 9、テレビ 8、ダイニングテーブル 8 が多い。ダイニングテーブルは 5% では 0/8 が通過する。電子レンジは 5/5、冷蔵庫は 4/5、テレビは 6/8 が 5% でも通過する。平らな面は狭い相対差でも揃う。

## 画像で見たこと

- Mini 3 の 14.3 秒。モニタ、キーボード、マウス、カップは箱として合っている。カップの箱には台も入り、それでも 99% 揃う。深度が滑らかだと、物体の外が少し混ざっても落ちない。
- ロフトの 9.0 秒。ベッドが couch、棚の小物が potted plant と tv になっている。クラスは違うが、面が平らなので 58% から 100% で採用される。
- 東京の映像の 3.0 秒は窓の外の街で、バルコニーの縦の繰り返しを traffic light と出している。遠い建物は深度が一様で、100% のまま採用される。5% でもこの種の平面は残る。

## 分かったこと

15%、50% という規定は、室内ではほぼすべての箱を通す。落としたのは、箱の中に明らかに違う奥行きが同居しているときだけである。

相対差を 5% に狭めると、テーブル、ソファ、人、椅子の一部が落ち、家電や画面のような平面は残る。狭めても、平らな場所に乗った誤ったクラスは残る。深度の一致は「そのクラスの物体か」ではなく「その箱が一つの面に近いか」を見ている。

仮説の「揃った画素はその物体に属する」は、面が一つなら画素はまとまる、というところまでは合っている。クラス名を物体の識別にする、というところは合っていない。

## 残った資産

- `object_observation_v1`。1フレームの箱、相対深度、相対差 5/10/15% の割合、5% の連結成分数。
- `object_map/extract_objects.py`。合成深度の `--self-check` を通してから映像を処理する。
- `object_map/out/summary.yaml` と、フレームごとの YAML、重ね JPEG。
- 映像と `yolo11n.pt` は Git に入れていない。

リアルタイム側も、地図側も、この YAML を観測にする。メートル位置と世界座標はまだ無い。

## 次の段

当初の段2（フレーム間で箱をつないでトラックにする）は承認しない。クラスが違っても面が平らなら通る観測を、時間方向へつなぐと、誤った名前のトラックが資産になる。

大監督者が承認する次の1段は、検出箱を使う前に、画像全体から相対差 5% の連結した面を取るものである。大きい面を `kind: plane` として同じ YAML に足し、検出箱がその面と重なるかを数える。これで、壁を大きい平面として置く仮説と、家具の箱が面の上に乗っているかを、同じ深度の関数で見られる。トラックと世界座標はその後である。
