
# 背景
- Orb slam3 では、精度がでていない
- Depth Anything3 単体も精度がでていない
- real time で自己位置推定をしたい
- offline で先にマップを作っておく
- マップ作成時　と　real time処理は　方式が変わりすぎると、一致しない

# 仮設
- object detectionで精度良く物体のBBoxを特定
- bbox内の一定面積以上(例えば 50%以上)、depthがおおよそ一致したら、bbox内はその物体に所属
- 点群でマップを作成したら、処理がおもすぎる気がする
- world map を yaml で管理し、位値、サイズを登録する。
- 壁などのおおきなものは、仮置きで、大きい平面として登録し、精度が上がればサイズを入れる

# 要求
- 似たような技術があれば、いいところを取り入れる
- 上記の仮設を軸として、必要に応じて、論文技術などを取り入れて改良して良い
- ローカルの動画だけでは判断が難しいので、室内動画をネットから10個ほどダウンロードOK
- 大監督者、小監督者、作業者A、....。作業者X（作業者の数は可変）に分かれる
- 大監督者は、レポートを読み、計画が1ステップずつ、技術の積み上げができることを確認する
  - これをやることで、これが分かる、これは資産になる　を確認する
  - 論文、ブログ、Xなどの技術調査は大監督者の役割
  - 少監督者に指示を出す
- 小監督者は、大きい計画の中で、各ステップの作業計画を建て、作業者の結果を確認し、次のステップを立て、大作業者に承認を得る
  - 少監督者からの指示に従う
  - ステップごとの md 作成は、小監督者の役割
- 外部データの clone は ./third_parth/　に保存
