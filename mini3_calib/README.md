# Mini 3 のカメラ内部パラメータ

## 背景

追跡に使っている `slam/config/mini3_1280x720.yaml` の焦点距離は、公称画角からの初期値である。歪み係数は Mini 3 Pro の公開値を出発点にしたもので、この機体では測っていない。

Mini 3 のピントは 1 m より先で、下り映像は 1280×720 である。校正もその画素のまま行う。別の解像度やデジタルズームで撮った値は、この追跡には使わない。

パターンは 27 型フルHD（1920×1080）のモニタに出す。印刷した板を用意せず、このパネルの対角から円の間隔をミリメートルにする。広告上の対角は表示面の対角なので、ベゼルは含めない。画素は正方形として扱う。パネルは Fast IPS、240 Hz、フリッカー防止付きである。

## 目的

モニタ上の白い円を Mini 3 で複数の向きから撮り、ピンホールモデルの `fx` `fy` `cx` `cy` と歪み `k1` `k2` `p1` `p2` `k3` を求める。結果は ORB-SLAM3 が読む YAML にする。

円は非対称グリッドで、1 行 4 個、5 行、合計 20 個。OpenCV の `findCirclesGrid` がこの並びを読む。円の直径は中心間隔の 0.84 倍で、この 1920×1080・対角 27 インチのパネルでは間隔が 61.1 mm、直径が 51.4 mm になる。1.5 m 先から焦点距離 730 画素の 1280×720 で見ると、円はおよそ 25 画素になる。

画面のミリメートルは姿勢の大きさにだけ効く。焦点距離の単位は画素なので、対角の指定が少し違っても `fx` はほとんど動かない。

## 使い方

OpenCV の Python が要る。この環境は 4.6 である。

プロペラを外し、機体を手で持つ。デジタルズームは使わない。距離は 1.5 m 以上。ピントが合わないほど近づかない。画面の反射が入らない位置から、グリッド全体が写るように撮る。

Mini 3 のジンバルは機体を傾けてもカメラを水平に戻す。機体を傾けても、モニタの写る角度は変わらない。角度はモニタ側で変える。スタンドは前に約 5°、後ろに約 20° 倒れ、縦に ±90° 回る。その範囲で板の向きを変え、機体はほぼ水平のまま前後左右と上下にずらす。円が映像の端に寄ったフレームも混ぜる。それが歪みの推定に効く。

### 1. モニタに円を出す

リポジトリのルートで実行する。パターンは 1920×1080、対角 27 インチで作る。出す画面は `DISPLAY_NAME` で、初期値は `HDMI-1` である。表示スケールは 100% にし、そのモニタへ全画面で出す。拡大表示のまま出すと、画素とミリメートルの対応がずれる。

```bash
python3 mini3_calib/show_pattern.py
```

全画面で円が出る。閉じるのは `q` か Esc。同じ実行が `mini3_calib/out/pattern.json` に間隔と画面サイズを書く。校正はこのファイルを読む。

対角が 27 インチでないときは `--diagonal-in` を変える。

```bash
python3 mini3_calib/show_pattern.py --diagonal-in 27
```

窓を出さず画像だけ欲しいときは `--dump` を付ける。画素数を変えるときは `--width` と `--height` を付ける。

```bash
python3 mini3_calib/show_pattern.py --dump mini3_calib/out/pattern.png
```

### 2. 下り映像を保存する

`scripts/mini3/recv.sh` で待受し、スマホから転送する。できた `.mp4` を校正に渡す。SLAM と同じ 1280×720 のままにする。

### 3. 動画から画像を選ぶ

`select_frames.py` は動画を先頭から1枚ずつ見る。円が `CIRCLE_COUNT` 個そろい、どの円も画面の端で切れておらず、芯が黒く欠けていなければ画像にする。そのあと `SKIP_FRAMES` 枚を飛ばして、また探す。個数が違う画像と、円が欠けた画像は削除する。条件はファイル冒頭の `USER_SETTINGS` である。

引数を省略すると `mini3_bridge/pc/recordings/` の mp4 を一つずつ処理する。画像は `out/frames/動画名/*.png` に書く。同じ動画をもう一度選ぶと、そのフォルダの画像は入れ替わる。

```bash
python3 mini3_calib/select_frames.py
```

1本だけ見るときは動画のパスを渡す。飛ばす枚数を変えるときは `SKIP_FRAMES` を書き換えて、同じコマンドを再実行する。

### 4. 校正する

引数を付けないと、`out/frames/` の日時分フォルダを番号で選ぶ。

```bash
python3 mini3_calib/calibrate.py
```

フォルダを直接渡すときは次のとおり。

```bash
python3 mini3_calib/calibrate.py --images mini3_calib/out/frames/20261001_2332
```

動画は見ない。グリッドが 6 枚未満だと終了する。

検出に成功した画像は `mini3_calib/out/detect/` に書く。結果の YAML は `mini3_calib/out/mini3.yaml`。再投影誤差の RMS と `fx` `fy` `cx` `cy` を標準出力に出す。

画像サイズが 1280×720 でないときは、その旨を出す。その YAML は今の追跡設定には入れない。

`mini3_calib/out/` は Git に入らない。
